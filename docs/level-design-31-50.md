# 第 31-50 关制作方案

状态：`feat/50-levels` 开发版本，未正式部署。保留前 30 关，新增两个主题章节，每章 10 关。

## 共同约束

- 王阿妹是陪玩家胡闹的队友，反馈共同庆祝，不羞辱玩家。
- 手机竖屏优先；400 x 600 逻辑画布，拖拽物不得离开容器。主要按钮为 116 x 66 逻辑像素，留出手指移动距离。
- 每关提供弱提示和明确操作提示，只有主动点击才显示。目标体验在 60 秒内完成，不设强制倒计时。
- 所有新关复用配置式引擎，无外部知识、真实设备权限、声音辨识或精准像素操作要求。
- 难度标记是策划估计，不是实测玩家统计；休息关和组合关穿插，不严格递增。
- 跳关沿用每日三次免费额度，标记为跳过而不是手动通关，只解锁下一关。广告奖励尚未接入，不模拟广告。
- 新关主要采用带按压反馈的 2D 玩具按钮，部分使用共享 3D 风格阿妹位图。不是实时 3D，也不是全部关卡重绘。
- 新增独立美术素材为 0；共享阿妹 PNG 为 203.4 KB，全部公开运行素材合计 924.7 KB。关卡素材遵守现有 300 KB 软预算，CI 检查总预算。

## 第四章：阿妹的摸鱼工坊

把工作的仪式感变成摸鱼道具。浅冷色背景配珊瑚、黄、蓝、薄荷色，不用大段说明。

| 关卡 | 主玩法 / 笑点 | 实际解法 | 估计难度 / 时间 |
| --- | --- | --- | --- |
| 31 摸鱼也要打卡 | 文字拖拽；工作也想休息 | 把「工作」拖到休息区，不是点休息区 | 轻松 / 10-20 秒 |
| 32 咖啡不是白开水 | 操作顺序；先给水只是在喝水 | 先点咖啡豆，再点水；顺序错了可重新操作 | 普通 / 15-35 秒 |
| 33 爪印也是签名 | 长按；阿妹代签 | 按住爪印章 1.2 秒，松手或移开会取消 | 轻松 / 10-25 秒 |
| 34 抽屉各回各家 | 三物件归位；收拾桌面 | 钥匙、零食、笔分别拖入对应抽屉，顺序不限 | 普通 / 20-45 秒 |
| 35 别叫醒摸鱼搭子 | 不操作；克制也是玩法 | 安静等 3 秒；点叫醒会失败，可以重试 | 轻松 / 5-20 秒 |

| 38 百分之百不靠谱 | 等待与真假状态；100% 不是完成 | 等 2.2 秒出现真实按钮，再点真实按钮 | 普通 / 10-30 秒 |
| 39 把周一放飞 | 方向滑动；纸飞机带走周一 | 在飞机上向上滑至少 52 逻辑像素，横滑无效 | 轻松 / 10-25 秒 |

## 第五章：离谱维修站

修理日常里那些不太靠谱的设备。玩笑围绕步骤、方向与状态，而不是依靠专业维修知识。

| 关卡 | 主玩法 / 笑点 | 实际解法 | 估计难度 / 时间 |
| --- | --- | --- | --- |
| 41 开关也想休息 | 三开关组合；不是全打开 | 打开 A 和 C，保持 B 关闭；错误开关可以恢复 | 普通 / 15-35 秒 |
| 42 插头不是按钮 | 拖拽而非点击 | 把插头拖进插座 | 轻松 / 10-20 秒 |
| 43 螺丝要稳稳地松 | 长按；锤子不是捷径 | 按住螺丝 1.6 秒，不依赖快速连点 | 轻松 / 10-25 秒 |
| 44 镜子里的右边 | 镜像方向；反常识滑动 | 在镜面物件上向左滑至少 52 逻辑像素 | 普通 / 15-35 秒 |
| 45 灯亮之前先通电 | 状态组合；电源与灯都需要 | 电源和灯都切换到开；不强制操作顺序 | 轻松 / 10-25 秒 |
| 46 耳朵友好音量 | 单轴拖动；舒服不等于静音 | 把音量滑块拖到「舒服」刻度，允许误差 | 普通 / 15-35 秒 |
| 47 圆有圆的家 | 形状归位 | 把圆形放入圆形目标，忽略方形目标 | 轻松 / 10-20 秒 |
| 48 拍醒电池 | 快速连点；假快充无效 | 在电池上快速点三次，相邻间隔小于 900 毫秒 | 普通 / 10-30 秒 |
| 49 倒数开机 | 倒序点击 | 按 3、2、1 顺序点按钮；顺序错可重新开始 | 普通 / 15-35 秒 |
| 50 阿妹的修理包 | 分步解锁；阿妹带工具玩家出力 | 按螺丝 1.2 秒解锁插头，把插头拖入插座，再点开机 | 较难 / 25-60 秒 |

## 配置与实现约定

- 每关配置位于 `packages/levels/src/configs/level-031.json` 至 `level-050.json`；配置包含对象、提示、胜利条件和成功/失败文案。
- 顺序判断使用事件尾序列，错误后可以通过完整正确序列恢复。第 50 关用逐步启用对象保证步骤，不靠玩家猜未激活控件。
- 拖拽目标在同一次拖动中只发一次事件，避免拖动结束重复发射破坏组合关。
- 长按计时归 Phaser 场景管理；松手、移开及场景销毁不会留下跨关卡定时器。
- 方向滑动检查主要轴、方向、最小位移，不把普通点击误判成滑动。音量关仅横向拖动，无音频要求。
- 开关状态变化可见，「关」和「开」文案随状态更新。图片按部署基础路径加载，以兼容 GitHub Pages 子目录。
